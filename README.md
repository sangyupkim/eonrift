# 영겁의 틈새

모바일 우선 웹 쿼터뷰 액션 RPG. 기획서는 [docs/GDD.md](docs/GDD.md)에 있습니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버 (같은 와이파이의 폰에서 http://<PC IP>:5173 으로 접속 가능)
npm run build      # 타입 검사 + 배포용 빌드 (저장소 최상단 index.html, assets/)
npm test           # 단위 테스트
```

주소 뒤에 `?debug`를 붙이면 브라우저 개발자 도구에서 `game` 객체로 게임 상태를 볼 수 있습니다.

## 조작

| 동작 | 모바일 | PC |
|---|---|---|
| 이동 | 화면 왼쪽 아무 곳이나 눌러 가상 조이스틱 | W A S D |
| 공격 / 채집 | 공격 버튼 (누르고 있으면 연속) | J 또는 마우스 왼쪽 클릭 |
| 구르기 (무적) | 구르기 버튼 | Space |
| 스킬 1·2·3 | 스킬 버튼 | 1 · 2 · 3 |
| 물약 | 물약 버튼 | Q |
| 상호작용 (대화, 채집, 입장, 워프) | 가까이 가면 나타나는 손 버튼 | E |
| 큰 지도 | 미니맵 누르기 | M |
| 가방 / 장비 | 오른쪽 위 버튼 | I |
| 차원집 건설 모드 | 오른쪽 위 망치 버튼 | B |
| 메뉴 | 오른쪽 위 버튼 | Esc |

## 배포

`main`에 올라가면 GitHub Actions가 테스트와 빌드를 한 뒤 GitHub Pages에 배포합니다.
저장소 **Settings → Pages → Source** 를 **GitHub Actions** 로 한 번만 설정하면 됩니다.

## 구조

```
src/
  config.ts            타일 크기, 카메라, 플레이어 수치
  core/                난수(시드), 입력, 효과음·배경음(Web Audio)
  data/                아이템, 직업·스킬, 장비, 몬스터, 7단계 테마, 공장 건물·레시피, 스토리 대사
  dungeon/             맵 생성기(순수 데이터), 충돌
  factory/             공장 시뮬레이션 (전력망, 레일, 기계, 오프라인 진행)
  models/              코드로 만드는 로우폴리 모델 (캐릭터, 몬스터, 마을, 공장 건물)
  game/                게임 루프, 전투, 몬스터 AI, 저장, 스토리 진행
  game/scenes/         차원마을, 차원던전, 차원집 장면
  ui/                  HUD, 조이스틱, 미니맵, 메뉴 화면, 대화창, 건설 도구
tests/                 맵 생성, 충돌, 가방, 공장, 성장·스토리 테스트
```
