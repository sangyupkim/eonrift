# 영겁의 틈새

모바일 우선 웹 쿼터뷰 액션 RPG. 기획서는 [docs/GDD.md](docs/GDD.md)에 있습니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버 (같은 와이파이의 폰에서 http://<PC IP>:5173 으로 접속 가능)
npm run build      # 타입 검사 + 배포용 빌드 (dist/)
npm test           # 단위 테스트
```

주소 뒤에 `?debug`를 붙이면 브라우저 개발자 도구에서 `game` 객체로 게임 상태를 볼 수 있습니다.

## 조작

| 동작 | 모바일 | PC |
|---|---|---|
| 이동 | 화면 왼쪽 아무 곳이나 눌러 가상 조이스틱 | W A S D |
| 공격 / 채집 | 공격 버튼 (누르고 있으면 연속) | J 또는 마우스 왼쪽 클릭 |
| 구르기 | 구르기 버튼 | Space |
| 상호작용 (귀환 등) | 가까이 가면 공격 버튼이 바뀜 | E |
| 가방 / 메뉴 | 우상단 버튼 | I / Esc |

## 구조

```
src/
  config.ts            타일 크기, 카메라, 플레이어 수치
  core/                난수(시드), 입력
  data/                아이템, 채집물, 7단계 던전 테마
  dungeon/             맵 생성기(순수 데이터), 충돌
  models/              코드로 만드는 로우폴리 모델 (검사, 채집물, 차원문, 장식)
  game/                게임 루프, 던전 장면, 플레이어, 가방, 파편 효과
  ui/                  HUD, 가상 조이스틱, 미니맵, 메뉴 화면
tests/                 맵 생성기·충돌·가방 테스트
```
