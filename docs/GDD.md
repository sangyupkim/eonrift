## 2. 게임의 세 기둥

| 기둥 | 역할 | 플레이 |
|---|---|---|
| **차원던전** | 모험과 전투 | 매번 바뀌는 맵에서 몬스터를 사냥하고 자원을 모은다 |
| **차원마을** | 거점과 스토리 | 상점, 강화, 퀘스트, NPC와의 대화, 스토리 진행 |
| **차원집** | 생산과 성장 | 던전에서 가져온 자원을 자동화 공장으로 가공한다 |

### 2.1 전체 순환 구조

```
            ┌──────────────── 스토리 진행 / 직업 해금 ────────────────┐
            │                                                          │
            ▼                                                          │
   ┌──────────────┐    원자재·전리품    ┌──────────────┐               │
   │   차원던전   │ ──────────────────▶ │    차원집    │               │
   │ (전투·수집)  │                     │ (공장·가공)  │               │
   └──────────────┘                     └──────────────┘               │
         ▲                                     │ 강화재료·제작품       │
         │ 더 강한 장비로 더 높은 난이도       ▼                       │
         │                              ┌──────────────┐               │
         └───────────────────────────── │   차원마을   │ ──────────────┘
                                        │(거래·강화·NPC)│
                                        └──────────────┘
```

- 던전에서는 **가공되지 않은 원자재**가 주로 나온다.
- 공장에서 가공해야 **강화재료, 소모품, 장비**가 된다.
- 마을에서 **강화, 거래, 퀘스트**를 하고 스토리를 진행한다.
- 강해지면 더 높은 난이도의 차원문에 들어가서 더 좋은 자원을 얻는다.

## 3. 세계관

### 3.1 배경 ✅
- **정통 판타지 + 마공학:** 검과 마법의 세계에, 마력을 동력으로 쓰는 기계 기술(마공학)이 섞여 있다.
- **차원틈새:** 여러 세계 사이에 있는 균열 공간. 여러 세계와 시대에서 사람들이 떨어져 들어온다.
- **차원마을** (마을 이름 ✅): 차원틈새로 떨어진 사람들이 모여 만든 마을. 이곳에서는 **나이를 먹지도, 죽지도 않는다.**
- **두 부류의 주민:**
  - **탈출파:** 전설을 믿고 틈새를 벗어나려는 사람들
  - **안주파:** 탈출을 포기하고 영원한 삶에 적응한 사람들
- **전설:** 차원던전 깊은 곳에 있는 특정 아이템들을 모으면 차원틈새를 탈출할 수 있다고 전해진다.
- **주인공:** 새로 틈새에 떨어진 사람. 전설을 좇아 모험을 시작한다.

### 3.2 설정 확장 제안 💡

| 요소 | 제안 내용 |
|---|---|
| 탈출 아이템 ✅ | **차원석** 7개. 1~7단계 차원던전의 최종 보스가 하나씩 지니고 있다 |
| 불사의 규칙 ✅ | 던전에서 쓰러지면 죽지 않고 **마을로 튕겨 나온다.** 이것을 게임의 사망 처리로 쓴다 (7.5 참고) |
| 마공학의 근원 ✅ | 몬스터를 쓰러뜨리면 나오는 **마력 정수**가 차원집 공장의 에너지원이다 |
| 차원집의 정체 | 들어가는 사람마다 다른 공간이 열리는 특이한 차원문. 누가 왜 만들었는지가 스토리의 떡밥이 된다 |
| 갈등 구조 ✅ | 탈출파와 안주파의 대립. 주인공의 선택에 따라 엔딩이 갈린다 (4.2 참고) |

### 3.3 주요 NPC 초안 💡

| NPC | 소속 | 역할 |
|---|---|---|
| 촌장 | 중립 | 마을의 가장 오래된 주민. 전설을 처음 알려준다 |
| 안내인 | 탈출파 | 주인공을 발견해 튜토리얼을 도와준다 |
| 대장장이 | 안주파 | 강화 담당. 탈출을 포기했지만 속으로는 흔들린다 |
| 마공학자 | 탈출파 | 차원집과 공장 기술을 알려준다 |
| 상인 | 안주파 | 아이템을 사고판다. 영원한 삶을 즐기는 인물 |
| 수수께끼의 인물 | ??? | 차원집과 탈출의 진실을 알고 있다 |

## 4. 스토리 구조 ✅/💡

- 대사와 일부 컷신이 있는 **스토리 중심 게임** ✅
- 챕터 구성 💡:

| 챕터 | 내용 | 해금 |
|---|---|---|
| 프롤로그 | 틈새로 떨어짐 → 마을에서 깨어남 → 튜토리얼 던전 | 차원마을, 1단계 차원문 |
| 1장 | 전설을 알게 되고 첫 번째 차원석을 얻는다 (1단계 보스) | **차원집**, 기초 공장, 2단계 차원문 |
| 2장 | 탈출파와 안주파의 갈등 (2~3단계) | **마법사** 직업 |
| 3장 | 차원집의 비밀 (4단계) | **궁수** 직업, 공장 확장 |
| 4~5장 | 깊은 던전, 차원석 수집 (5~7단계) | 고단계 차원문 |
| 최종장 | 차원석 7개를 모은 뒤, 탈출파/안주파 중 한쪽을 선택 | 엔딩 A / B |

### 4.2 엔딩 ✅
- **멀티 엔딩:** 탈출파를 따르는 엔딩 A, 안주파를 따르는 엔딩 B
- **두 엔딩 모두 루프 구조:** 어느 쪽을 골라도 결국 다시 차원틈새로 돌아온다.
  - 💡 엔딩 A (탈출): 차원석으로 틈새를 열고 나가지만, 도착한 곳은 처음 떨어졌던 순간의 차원틈새다.
  - 💡 엔딩 B (안주): 차원석을 봉인하고 마을에 남지만, 새로 떨어진 "누군가"가 과거의 주인공이다.
  - 💡 엔딩 후 **회차 플레이(2회차)**: 장비와 공장을 이어받고 난이도가 올라간 상태로 다시 시작한다. 루프 설정과 자연스럽게 맞물린다.

### 4.3 대사·컷신 연출 💡
- **대화:** 화면 하단 대화창 + 화자 이름 + 선택지(일부). 3D 캐릭터가 말할 때 머리 위에 말풍선 아이콘을 띄운다.
- **컷신:** 게임 안에서 연출한다. 카메라 각도는 고정하고 위치만 이동한다. 캐릭터 이동과 애니메이션, 화면 페이드, 흔들림을 쓴다.
- **스크립트:** 대사와 컷신은 데이터 파일(JSON)로 작성해서 코드 수정 없이 추가·수정할 수 있게 한다.
- 모든 컷신은 **건너뛰기**를 지원한다.

## 7. 차원던전 ✅/💡

### 7.1 차원문과 난이도
- 마을의 **차원문 광장**에 여러 개의 차원문이 열려 있다 ✅
- 난이도가 높을수록 몬스터가 강하고 자원이 좋다 ✅
- 던전은 **7단계** ✅. 각 단계의 최종 보스가 **차원석**을 하나씩 지닌다.

| 단계 | 지형 테마 💡 | 권장 레벨 💡 | 주요 자원 💡 |
|---|---|---|---|
| 1단계 | 이끼 낀 숲 유적 | 1~5 | 철광석, 목재 |
| 2단계 | 붉은 협곡 | 5~10 | 구리광석, 목재, 짐승 가죽(몬스터) |
| 3단계 | 얼어붙은 동굴 | 10~15 | 은광석, 서리 결정 |
| 4단계 | 수정 광맥 | 15~20 | 마력 수정, 미스릴 |
| 5단계 | 폐허가 된 마공학 공장 | 20~25 | 톱니 부품, 마공 합금 |
| 6단계 | 용암 심연 | 25~30 | 흑요석, 화염 핵 |
| 7단계 | 부서진 차원 | 30+ | 차원 결정, 공허석 |

- 단계마다 **마력 정수**(공장 에너지원)가 몬스터에게서 나온다. 단계가 높을수록 상위 정수가 나온다.
- 이전 단계의 보스를 쓰러뜨리면 다음 단계 차원문이 열린다 💡

### 7.2 맵 생성 ✅/💡
- 들어갈 때마다 **맵 형태, 자원 배치, 몬스터 배치가 무작위로 바뀐다** ✅
- 맵 크기는 **한 화면의 약 10배** ✅

**크기 산정 💡:**
- 한 화면에 보이는 범위 ≈ 가로 16칸 × 세로 9칸 (1칸 = 캐릭터 약 1.5명 너비)
- 한 화면 ≈ 144칸 → 10배 ≈ **약 1,440칸 → 40×36칸 정도의 격자**
- 이 중 실제로 걸을 수 있는 바닥은 약 40%이고, 나머지는 벽과 빈 공간이다 (방 8~10개 + 폭 2칸 통로)

**생성 방식 💡:** 방 + 통로 구조
```
 ┌───┐      ┌─────┐
 │시작│──────│전투 │────┐
 └───┘      └─────┘    │   ┌──────┐
               │       └───│ 자원 │
            ┌─────┐        └──────┘
            │정예 │──────┐
            └─────┘   ┌──────┐
                      │ 출구 │ (보스 방 또는 귀환 차원문)
                      └──────┘
```
- 방 6~10개를 통로로 연결한다.
- 방 종류: **시작 / 전투 / 자원(채집) / 정예 몬스터 / 보물 / 출구(보스)**
- 같은 시드 값이면 같은 맵이 나오게 해서 버그를 재현할 수 있게 한다.
- 단계마다 지형 테마(바닥·벽 색, 장식물)를 다르게 한다.

### 7.3 던전 한 판의 흐름 💡
1. 차원문으로 입장 → 시작 방
2. 탐험하며 몬스터 사냥, 자원 채집 (광맥, 나무, 마력 결정 등을 공격하듯 두드려서 채집)
3. 출구 방의 보스를 잡거나 **귀환석**을 써서 마을로 복귀
4. 목표 플레이 시간: 한 판 **5~10분**

### 7.4 가방 ✅/💡
| 가방 | 칸 수 💡 | 쓰러졌을 때 |
|---|---|---|
| 일반 가방 | 20칸 | **모두 잃는다** ✅ |
| **차원가방** | 4칸에서 시작 | **지켜진다** ✅ |

- 차원가방은 칸이 적다. 무엇을 넣을지 고르는 판단이 생긴다 💡
- 차원가방 칸은 공장 제작과 스토리로 늘린다 💡
- 무사히 귀환(보스 처치 후 귀환 차원문 또는 귀환석)하면 두 가방 모두 가져온다.

### 7.5 쓰러짐 처리 (불사 설정 활용) ✅
- HP가 0이 되면 **마을로 강제 귀환**된다 (죽지 않는 세계관을 반영).
- **착용 중인 장비:** 그대로 유지
- **일반 가방의 아이템:** 모두 사라짐
- **차원가방의 아이템:** 그대로 가져옴

| 게시판 | 서브 퀘스트 (특정 자원 납품, 특정 몬스터 사냥) | 💡 |
| 직업의 전당 | 직업 변경 | 💡 |
| 창고 | 아이템 보관 | 💡 |

- 마을은 걸어 다니는 3D 공간이다. 탈출파가 모여 사는 구역과 안주파 구역으로 분위기를 나눈다 💡
- 스토리가 진행되면 마을에 새 NPC와 시설이 생긴다 💡

## 9. 차원집 (공장 자동화) ✅/💡

### 9.1 개념 ✅
- 들어가는 사람마다 독립된 공간이 열리는 차원문 안의 개인 공간
- 처음에는 **정해진 타일 칸**만 주어진다
- **에너지 공급 → 공장 가동 → 레일 운반 → 완성품** 흐름의 공장 게임을 RPG 안에 넣는다

### 9.2 기본 흐름 💡

```
[투입 상자] ──레일──▶ [제련로] ──레일──▶ [조립기] ──레일──▶ [출하 상자]
 (던전 자원)            ▲                    ▲                (완성품)
                        │                    │
                 [마력 발전기] ····마력선···· ┘
                  (마력 정수 → 에너지)
```

### 9.3 건물 목록 초안 💡

| 분류 | 건물 | 기능 |
|---|---|---|
| 에너지 | 마력 발전기 | **마력 정수**(몬스터 드롭)를 태워 에너지를 만든다 ✅ |
| 에너지 | 마력선 (전선) | 발전기와 건물을 **직접 연결**해서 에너지를 보낸다 ✅ |
| 에너지 | 마력 축전기 | 남는 에너지를 저장한다 💡 |
| 운반 | 레일 (컨베이어) | 아이템을 한 방향으로 옮긴다 |
| 운반 | 분배기 / 합류기 | 레일을 나누거나 합친다 |
| 저장 | 투입 상자 | 가방의 자원을 넣는 곳. 공장의 시작점 |
| 저장 | 출하 상자 | 완성품이 쌓인다. 마을 창고와 연동된다 |
| 가공 | 제련로 | 광석 → 주괴 |
| 가공 | 분쇄기 | 광석·뼈 → 가루 |
| 가공 | 마력 주입기 | 주괴 + 에너지 → 마력 주괴 |
| 가공 | 조립기 | 여러 재료 → 강화석, 포션, 장비 부품 |
| 가공 | 연금 솥 | 약초 + 가루 → 포션 |

### 9.4 생산품 예시 💡

```
철광석 ─[제련로]─▶ 철 주괴 ─[마력 주입기]─▶ 마력 철 ─┐
                                                      ├─[조립기]─▶ 하급 강화석
마력 정수 ─[분쇄기]─▶ 마력 가루 ─────────────────────────┘
```
- 강화석 (장비 강화 재료)
- 포션 (HP·MP 회복)
- 장비 (설계도가 있어야 제작 가능)
- 귀환석, 가방 확장 키트
- **차원가방 확장 키트**
- **차원석 공명 장치** — 차원석의 힘을 끌어내는 스토리 핵심 장치를 공장에서 완성하게 해서 세 기둥을 하나로 묶는다

### 9.5 성장 요소 💡
- **타일 확장:** 처음 8×8칸 → 자원을 투자해 12×12, 16×16, 24×24칸으로 넓힌다.
- **설계도:** 던전에서 얻거나 스토리로 해금해서 새 건물과 레시피를 연다.
- **건물 등급:** 같은 건물의 상위 버전 (처리 속도 상승)

### 9.6 모바일 조작 💡
- 차원집 안에서도 캐릭터가 걸어 다닌다. **건설 모드 버튼**을 누르면 건설 화면으로 바뀐다.
- 건설 모드: 하단에 건물 목록, 탭으로 배치, 회전 버튼, 레일과 마력선은 **손가락으로 드래그해서 연속 배치**
- 건물을 탭하면 정보 창 (가동 상태, 입출력, 철거)

### 9.7 오프라인 진행 ✅
- 던전에 가 있는 동안에도 공장은 계속 돌아간다.
- 게임을 껐다 켜면 **오프라인 보상**으로 흐른 시간만큼의 생산량을 계산해서 지급한다 ✅
- 상한 시간은 💡 기본 8시간, 공장 업그레이드로 늘린다.
- 투입 자원과 마력 정수가 떨어지면 그 시점에서 생산이 멈춘다 (무한 생산 방지).
- 공장은 모든 직업이 공유한다 ✅

## 10. 전투 시스템 💡

### 10.1 공통
- **회피:** 구르기 약 0.4초 동안 무적. 쿨다운 1초
- **타격감:** 히트스탑(0.05초), 피격 시 흰색 번쩍임, 넉백, 데미지 숫자, 치명타 연출, 화면 흔들림

### 10.2 몬스터 AI
```
대기 ──(플레이어 감지)──▶ 추적 ──(사거리 진입)──▶ 공격 예고 ──▶ 공격 ──▶ 후딜레이
  ▲                                                                   │
  └────────────────────(플레이어 이탈)─────────────────────────────────┘
```
- **공격 예고:** 바닥에 빨간 범위를 표시해서 모바일에서도 피할 수 있게 한다.
- 유형: 근접, 원거리, 돌진형, 자폭형, 탱커형, 소환형
- 테마 예시: 차원에 오염된 짐승, 폭주한 마공학 골렘, 차원 틈새의 망령

### 10.3 보스
- HP 비율에 따라 2~3 페이즈로 나뉜다
- 큰 범위 공격을 예고하고, 피하면 반격 기회가 오는 패턴

## 11. 성장 시스템 💡

| 요소 | 내용 | 주요 획득처 |
|---|---|---|
| 레벨 | 경험치로 레벨업, 기본 스탯 상승 | 던전 몬스터 |
| 장비 | 무기, 방어구, 장신구 (3슬롯) | 던전 드롭, 공장 제작 |
| 장비 등급 | 일반 → 고급 → 희귀 → 영웅 → 전설 | |

## 12. 기술 설계 💡

| 항목 | 선택 |
|---|---|
| 렌더링 | Three.js |
| 언어 / 빌드 | TypeScript + Vite |
| 모델 | 기본 도형을 조합한 절차적 로우폴리 모델 |
| 던전 생성 | 시드 기반 절차적 생성 (방 + 통로) |
| 충돌 | 격자 기반 충돌 + 원형 충돌 (물리 엔진 없음) |
| 공장 시뮬레이션 | 고정 간격 틱(예: 초당 10회) 시뮬레이션. 렌더링과 분리 |
| 스토리 | JSON 스크립트 기반 대화·컷신 시스템 |
| 저장 | localStorage (자동 저장). 나중에 파일 내보내기/불러오기 지원 |
| 사운드 | Web Audio API |
| 배포 | 정적 호스팅 + PWA (홈 화면 추가, 전체 화면, 가로 모드 고정) |

### 12.1 성능 목표 (모바일)
- 중급 안드로이드 / iPhone에서 60fps (최소 30fps 유지)
- 던전 40×36칸: 바닥과 벽은 인스턴싱으로 묶고, 화면 밖 오브젝트는 그리지 않는다.
- 공장: 레일 위 아이템은 인스턴싱으로 한 번에 그린다.
- 첫 로딩 3초 이내
- 그래픽 품질 옵션 (그림자, 해상도 배율)

### 12.2 씬 구성
```
타이틀 ─▶ 차원마을 ─┬─▶ 차원던전 (등급별)
                    └─▶ 차원집 (공장)
```
