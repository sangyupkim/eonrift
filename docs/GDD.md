---

## 2. 디자인 방향

1. **한 손가락씩 쓰는 조작:** 왼손은 조이스틱, 오른손은 버튼. 정밀한 조준이 필요 없도록 자동 조준을 넣는다.
2. **손맛:** 히트스탑, 넉백, 화면 흔들림, 데미지 숫자로 타격감을 만든다.
3. **짧은 세션:** 한 판(스테이지)은 3~5분. 이동 중에 켜서 한 판 하고 끌 수 있게 한다.
4. **가벼운 실행:** 설치 없이 URL로 바로 실행하고 로딩은 빠르게. 외부 모델 파일 없이 코드로 모델을 만든다.

## 3. 코어 루프 💡

```
마을(허브) ──▶ 스테이지 선택 ──▶ 전투 (몬스터 처치 → 보스)
   ▲                                   │
   │                                   ▼
장비 강화 / 스킬 습득 ◀── 보상 획득 (경험치, 골드, 장비)
```

- **짧은 루프:** 적 처치 → 경험치·드롭 → 레벨업
- **중간 루프:** 스테이지 클리어 → 장비 교체·강화 → 다음 스테이지 해금
- **긴 루프:** 챕터 보스 → 새 지역 해금 → 난이도 상승

## 4. 조작

### 4.1 모바일 (메인) ✅/💡

```
┌──────────────────────────────────────────────┐
│ [HP/MP 바]                     [미니맵] [⏸]  │
│                                              │
│                                              │
│                                   (스킬2)    │
│                            (스킬1)    (스킬3)│
│   ╭───╮                                      │
│   │ ● │  ← 가상 조이스틱        (회피) (공격)│
│   ╰───╯                                      │
└──────────────────────────────────────────────┘
```

| 입력 | 동작 | 상태 |
|---|---|---|
| 좌하단 가상 조이스틱 | 8방향이 아닌 360° 아날로그 이동. 기울기에 따라 걷기/달리기 | ✅ |
| 조이스틱 방식 | **플로팅:** 화면 왼쪽 절반 어디를 터치해도 그 자리에 조이스틱이 생김 (기본 위치는 좌하단) | 💡 |
| 공격 버튼 (우하단, 가장 큼) | 기본 공격. 연타하면 3타 콤보, 누르고 있으면 자동 연속 공격 | 💡 |
| 회피 버튼 | 이동 방향으로 구르기. 짧은 무적 시간, 쿨다운 있음 | 💡 |
| 스킬 버튼 ×3 | 쿨다운 스킬 | 💡 |
| 자동 조준 | 공격·스킬 사용 시 일정 반경 안의 가장 가까운 적 쪽으로 자동으로 몸을 돌림 | 💡 |

- 멀티터치 지원: 이동하면서 공격할 수 있어야 한다.
- 버튼 크기는 최소 56px 이상으로 하고, 엄지 닿는 범위에 배치한다.

### 4.2 PC 💡

| 키 | 동작 |
|---|---|
| W A S D | 이동 ✅ |
| J 또는 마우스 좌클릭 | 공격 |
| Space | 회피 |
| 1 / 2 / 3 | 스킬 |
| Esc | 일시정지 |

## 5. 카메라 ✅/💡

- 직교(Orthographic) 카메라, 수평 45° / 수직 약 35° 고정 ✅
- 플레이어를 부드럽게 따라감 (살짝 지연되는 추적) 💡
- 벽이나 나무가 플레이어를 가리면 해당 오브젝트를 반투명하게 처리 💡
- 타격 시 짧은 화면 흔들림 💡

---

## 6. 전투 시스템 💡

### 6.1 플레이어
- **기본 공격:** 3타 콤보. 3타째는 범위가 넓고 넉백이 있다.
- **회피:** 구르기 약 0.4초 중 무적. 쿨다운 1초.
- **스킬:** 3슬롯. 예) 돌진 베기, 회전 베기, 충격파.
- **타격감:** 히트스탑(0.05초), 적 피격 시 흰색 번쩍임, 넉백, 데미지 숫자, 치명타 연출.

### 6.2 몬스터 AI
```
대기 ──(플레이어 감지)──▶ 추적 ──(사거리 진입)──▶ 공격 예고 ──▶ 공격 ──▶ 후딜레이
  ▲                                                                   │
  └────────────────────(플레이어 이탈)─────────────────────────────────┘
```
- **공격 예고:** 바닥에 빨간 범위 표시를 띄워 모바일에서도 피할 수 있게 한다.
- 몬스터 유형: 근접, 원거리, 돌진형, 자폭형, 탱커형.

### 6.3 보스
- 페이즈 2~3단계 (HP 비율에 따라 패턴 추가)
- 큰 범위 공격을 예고한 뒤 회피를 유도하는 설계

## 7. 성장 시스템 💡

| 요소 | 내용 |
|---|---|
| 레벨 | 경험치로 레벨업. 레벨업 시 기본 스탯 상승 |
| 스탯 | HP, 공격력, 방어력, 치명타 확률, 치명타 피해, 이동 속도 |
| 장비 슬롯 | 무기, 방어구, 장신구 (3슬롯으로 단순하게) |
| 장비 등급 | 일반(흰) → 고급(초록) → 희귀(파랑) → 영웅(보라) → 전설(주황) |
| 강화 | 골드로 장비 +1 ~ +10 강화 |
| 스킬 | 레벨에 따라 해금, 스킬 포인트로 강화 |

- 장비를 바꾸면 **캐릭터 모델의 무기 모양도 바뀌게** 한다 (코드 모델이라 쉽게 할 수 있다).

## 8. 콘텐츠 구성

### 8.1 MVP (첫 번째 플레이 가능 버전) 💡
- 마을(허브) 1개: 상점, 대장간(강화), 스테이지 입구
- 스테이지 3개 + 보스 1마리
- 일반 몬스터 4종 + 보스 1종
- 플레이어 캐릭터 1종 (근접 전사), 스킬 3개
- 장비 아이템 약 15종

### 8.2 이후 확장 ❓
- 직업 추가 (궁수, 마법사)
- 챕터 추가
- 무한 던전 / 웨이브 모드
- 업적, 일일 도전

## 10. 아트 가이드 💡

- **로우폴리 + 플랫 셰이딩.** 텍스처 없이 정점 색상과 단색 머티리얼만 쓴다.
- **캐릭터 비율:** 2~2.5등신. 머리를 크게 해서 쿼터뷰에서도 식별이 잘 되게 한다.
- **색 규칙:** 플레이어는 밝은 파랑 계열, 적은 빨강·보라 계열, 상호작용 오브젝트는 노랑 강조.
- **조명:** 방향광 1개 + 환경광. 그림자는 플레이어와 주요 오브젝트만 드리운다.
- **애니메이션:** 코드로 제어하는 관절 회전 (대기, 걷기, 달리기, 공격 3종, 구르기, 피격, 사망).

## 11. 기술 설계 💡

| 항목 | 선택 |
|---|---|
| 렌더링 | Three.js |
| 언어 / 빌드 | TypeScript + Vite |
| 모델 | 기본 도형을 조합한 절차적 로우폴리 모델 (코드) |
| 충돌 | 자체 구현한 원형·박스 충돌 (물리 엔진 없음, 가볍게) |
| 맵 | 타일 기반 데이터(JSON)로 맵 구성 |
| 저장 | localStorage (자동 저장) |
| 사운드 | Web Audio API. 효과음은 절차적으로 생성하거나 무료 에셋 사용 |
| 배포 | 정적 호스팅 (GitHub Pages 등). PWA로 홈 화면 추가 지원 |

### 성능 목표 (모바일 기준)
- 중급 안드로이드 / iPhone에서 60fps (최소 30fps 유지)
- 드로우콜 100 이하. 같은 오브젝트는 인스턴싱으로 묶는다.
- 첫 로딩 3초 이내 (번들 크기 1MB 이하 목표)
- 그래픽 품질 옵션: 그림자와 해상도 배율 조절

## 13. 미정 사항 (결정 필요) ❓

1. **세계관 / 테마:** 정통 판타지, 동양 판타지, 포스트 아포칼립스, 귀여운 동화풍 등
2. **주인공 직업:** 첫 직업을 근접 전사로 해도 되는지
3. **스테이지 구조:** 정해진 맵(수동 제작)인지, 매번 바뀌는 랜덤 던전(로그라이크)인지
4. **스토리 비중:** 대사와 컷신이 있는지, 전투 위주로 최소한만 둘지
5. **수익화:** 광고나 결제를 넣을 계획이 있는지 (구조 설계에 영향이 있다)
6. **화면 방향:** 가로 고정으로 해도 되는지
